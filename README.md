# Kuherfassung mit Kamera · MUKAMS

Die [Kuherfassung](https://mukams.martinstuder.ch/?bestand=demo) speichert Kuhprofile, Kameraadressen und bestätigte Referenzfotos im jeweiligen Browser. Die Demoherde verwendet fiktive Stammdaten und Kuhbilder von Neill Campbell, Tilo Burghardt, Phoenix Yu und Andrew Dowsey (2024), University of Bristol. [MultiCamCows2024](https://doi.org/10.5523/bris.2inu67jru7a6821kkgehxg3cv2)
